🎲 Player Simulations

Monte Carlo simulations estimate fantasy-point distributions using each player's projection and ceiling. This first version uses a simplified distribution, not a possession-level game model.

Choose All players or an individual player, then select Run Simulations.

🏆 NBA Lineup Optimizer

Build valid eight-player DraftKings classic NBA lineups: PG, SG, SF, PF, C, G, F and UTIL, with a $50,000 salary cap. Players can fill only one slot, and every lineup must include players from at least two different NBA games. Earlier starts take PG, SG, SF, PF and C where eligible; later starts are prioritized in G, F and UTIL, with the latest eligible player in UTIL.

Simulation results

Uses each player’s simulated mean as their projection and 95th percentile as their ceiling. Run All players in Simulations first.

Late Swap Optimizer

Upload a filled DraftKings entries CSV. Started players stay in their exact imported roster slots. Only players whose games have not started can fill the remaining slots.

1 · Import current entries

Include Entry ID and all eight filled roster columns. An embedded salary table is read automatically and existing matching projections are kept. Entries remain in this browser.

2 · Update projections

Match by ID, or Name when no ID is supplied. Columns: Projection, Ceiling, Ownership, Minutes. You can also edit or boost players in Projections before running.

3 · Review locks and optimize

Locks use scheduled DraftKings game times in America/New_York and any LOCKED markers in the entries CSV. Check postponed games on DraftKings. A detected lock never clears automatically.

Uses player fades, player locks and team limits from Projections and Optimizer. Started players stay locked even if faded. Exposure and unique-player settings do not apply across imported entries. Search is randomized; a legal original lineup is retained if no better option is found. Later unstarted players are prioritized in flex slots.
