🎲 Player Simulations

Monte Carlo simulations estimate fantasy-point distributions using each player's projection and ceiling. This first version uses a simplified distribution, not a possession-level game model.

Load players and select Run Simulations.

🏆 NBA Lineup Optimizer

Build valid eight-player DraftKings classic NBA lineups: PG, SG, SF, PF, C, G, F and UTIL, with a $50,000 salary cap. Players can fill only one slot.

Choose your settings, then generate lineups.

This is a randomized search optimizer, not a guaranteed global optimum. Ownership is an input estimate, not a live feed. Exposure is enforced as a maximum count across generated lineups when feasible.
